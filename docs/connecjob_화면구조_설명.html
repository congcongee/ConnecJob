ConnecJob 화면 구조와 디자인 설명

발표·리뷰에서 "왜 이렇게 만들었나"에 답하기 위한 정리

1. 한 줄 요약

ConnecJob 은 두 기둥으로 되어 있다.

기둥누구를 위해하는 일화면
① 직무 탐구AI·데이터 분야가 처음이라 어떤 직무가 있는지 모르는 사람직무별 하는 일, 많이 요구하는 기술, 나에게 맞는 직무 찾기/guide/
② 경험으로 지원 준비 (핵심)자기 경험이 있고 지원을 준비하는 사람경험 입력 → 공고 추천 → 부족한 기술 → 자소서 초안·첨삭/match/ → /result/ → /letter/

공고 목록(/jobs/)은 두 기둥을 받쳐 주는 자료이고, 지난 결과(/history/)는 ②에서 나온 내 기록이다.

2. 사이트 지도

홈 /
├─ ① 직무 탐구 /guide/
│    ├─ 직무별 설명 → 그 직무 공고 /jobs/?group=
│    └─ 맞는 직무 찾기 /guide/#check → ②로 이어짐
├─ ② 경험으로 지원 준비 /match/            (경험 입력)
│    └─ 추천 결과 /result/<번호>/            (맞는 공고 + 부족한 기술)
│         └─ 자소서 /result/<번호>/letter/<공고>/   (초안 생성·첨삭)
│              └─ 자소서 보기 /letter/<번호>/
├─ 공고 둘러보기 /jobs/  → 공고 상세 /jobs/<공고>/
└─ 지난 결과 /history/   (②에서 나온 결과와 자소서 모음)

3. 메뉴(상단 띠) 구성

위치항목이유
왼쪽직무 탐구 · 경험으로 지원 준비 · 공고 둘러보기사이트가 하는 일. 기둥 순서(①→②) 그대로, 자료인 공고는 마지막
오른쪽지난 결과 · 로그인 · 회원가입내 것(개인 영역). 지난 결과는 기능이 아니라 내 기록이라 로그인 옆에 둠. 세 메뉴보다 한 단계 작은 글씨
왼쪽 끝 ☰전체 메뉴좁은 화면에서 위 메뉴가 숨으므로 모든 화면을 여기서 갈 수 있게 함 (홈, 공고, 직무 탐구, 지원 준비, 지난 결과)
  • 메뉴 이름, 화면 제목, 홈 카드 제목, 버튼 문구를 같은 말("직무 탐구", "경험으로 지원 준비")로 통일했다. 예전에는 "직무 알아보기 / 맞춤 추천"처럼 곳마다 말이 달라서 사이트가 무엇을 하는지 한눈에 안 들어왔다.
  • 지금 있는 화면의 메뉴에는 흰 밑줄이 생긴다.
  • 비회원도 지난 결과를 볼 수 있다(이 브라우저에서만). 로그인하면 비회원 때 결과가 계정으로 옮겨진다.

4. 홈 화면 위에서 아래로

순서구역무엇왜
0첫 화면(사진)화면 폭을 꽉 채운 사진 위에 슬로건·소개, 사진 아래 가운데에 "더 알아보기 ⌄"3초 안에 "직무 탐구부터 지원 준비까지 한곳에서"를 전달하고, 사이트의 두 기둥을 목차처럼 보여 줌
1두 가지로 도와 드려요 (두 기둥 카드)① 직무 탐구 / ② 경험으로 지원 준비 카드. "더 알아보기"를 누르면 여기로 내려오고 카드가 뿅 나타남홈의 유일한 입구. 카드를 누르면 직무 탐구 화면 / 경험 입력 화면으로 바로 이동
2직무 둘러보기직무 묶음 카드(누르면 그 직무 공고), "맞는 직무 찾기"홈에서 바로 맛보기. 위 카드와 같은 이름·번호를 쓰지 않아 중복으로 안 보임
3경험 한 줄로 바로 시작하기경험 적는 칸, 추천 예시, 내 최근 결과홈에서 바로 시작할 수 있게 (적은 글은 다음 화면으로 넘어감)
4마감 임박 공고마감이 가까운 실제 공고, 검색기둥을 받쳐 주는 자료라 아래에 둠
5마무리 띠"경험 하나만 적어 보세요" + 경험 적기끝까지 내려온 사람을 다시 ②로

예전에는 위 카드와 아래 구역이 같은 번호·제목(1 직무 탐구 / 2 경험으로 지원 준비)을 써서 같은 내용이 두 번 나오는 것처럼 보였다. 지금은 번호·제목은 카드에만 두고, 아래 구역은 "직무 둘러보기", "경험 한 줄로 바로 시작하기"처럼 하는 일 이름으로 구분한다. 구역 사이는 굵은 파란 선 대신 얇은 회색 선과 여백으로 나눈다.

5. 디자인 포인트

첫 화면과 "더 알아보기"

  • 첫 화면에는 슬로건 MATCH YOUR JOB., "직무 탐구부터 지원 준비까지 한곳에서", 소개 두 줄만 둔다. 버튼은 두지 않았다.
  • 화면 폭을 꽉 채운 사진 : 시원하고 첫인상이 강하다. 대신 높이는 창보다 조금 작게 해서 사진이 화면을 다 덮지 않게 했다.
  • 높이는 창보다 조금 작게 해서 아래 "ConnecJob 이 하는 일 / 두 가지로 도와 드려요" 제목이 첫 화면에 보이게 했다. 아래에 더 있다는 신호.
  • 더 알아보기 ⌄ : 사진 아래 가운데에 작은 흰 글씨와 얇은 꺾쇠만 둔다. 동그란 버튼 상자를 쓰지 않아 사진을 가리지 않고 가볍다. 누르면 바로 아래 두 기둥 카드로 부드럽게 내려가고, 꺾쇠가 살짝 위아래로 움직여 "아래에 더 있다"를 알린다. 아래 제목은 같은 가운데 줄에 둔다.
  • 카드 판은 화면에 들어올 때 아래에서 살짝 커지며 뿅 떠오른다(한 번만). 움직임을 줄이는 설정을 켠 사용자에겐 움직임 없이 바로 보인다.
  • 예전에는 첫 화면 버튼 2개와 바로 아래 카드에 같은 버튼이 두 번씩 나와 복잡해서, 첫 화면 버튼을 없애고 카드 하나로 모았다.

두 기둥 카드

  • 칸 전체가 링크. 카드 어디를 눌러도 해당 화면(직무 탐구 / 경험 입력)으로 바로 이동한다. 바깥에 큰 흰 판을 두지 않고 카드 두 장만 나란히 둬서 상자가 겹겹이 보이지 않게 했다. 마우스를 올리면 테두리가 파래지고 화살표가 오른쪽으로 움직여 "누를 수 있다"를 알려 준다.
  • 줄 맞춤. 제목·설명·항목·버튼이 양쪽 카드에서 같은 높이에 온다(CSS subgrid). 글 길이가 달라도 버튼 줄이 어긋나지 않는다.
  • ②의 항목 사이 화살표(→)는 순서가 있는 과정이라는 뜻. ①은 순서가 없으니 화살표가 없다.

버튼 강조 규칙

  • 한 화면에 진한 버튼은 하나. 둘 다 진하면 어디를 눌러야 할지 흐려진다.
  • 메인은 ② 경험으로 지원 준비(진한 파랑). 실제 결과(공고 추천, 자소서)를 주는 핵심 기능이기 때문.
  • ① 직무 탐구는 한 단계 약하게(연한 파랑). 덜 중요해서가 아니라 ②로 가기 전 입구라서. 순서는 ① 왼쪽, ② 오른쪽으로 흐름 그대로.

화면 폭별

  • 데스크톱·태블릿: 두 기둥 카드가 나란히.
  • 휴대폰: 카드가 세로로 쌓이고, 위 메뉴는 ☰ 전체 메뉴로 들어간다. 휴대폰도 사진이 폭을 꽉 채우고, 첫 화면에 "더 알아보기"와 아래 제목까지 보인다. 화면 옆으로 넘치는 부분 없음.

6. 예상 질문

왜 메뉴가 셋인가?
기둥 둘 + 자료 하나. 지난 결과는 기능이 아니라 내 기록이라 개인 영역(오른쪽)에 있다.
자소서 메뉴는 왜 따로 없나?
자소서는 "어느 공고에 낼지"가 정해져야 쓸 수 있다. 그래서 추천 결과의 각 공고에서 "자소서 쓰기"로 들어가고, 쓴 자소서는 지난 결과에 모인다.
왜 ②가 메인인가?
서비스가 실제로 결과를 만들어 주는 곳이 ②다. ①은 ②로 가기 전 단계.
공고 목록은 왜 홈 아래쪽인가?
공고는 다른 사이트에도 있다. ConnecJob 만의 가치는 "내 경험에 맞는 공고와 자소서"라서 그 기능을 위에 두었다.
